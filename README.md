# OASIS / MOVA Hand Avatar Code Staging

This is a private staging repository for the OASIS / MOVA hand avatar reconstruction code.

The code is still under cleanup and this repository is not a full public release. At this stage, it contains only selected core Python files for reviewing the code structure.

Project page: https://mova-hand.github.io/MOVA/

## Current Contents

- Main training, finetuning, inference, testing, and rendering entry scripts.
- Core LHM model, runner, rendering, utility, and loss modules.
- Selected hand avatar, SMPL-X, pose estimation, scene, and evaluation helper modules.

No logs, outputs, assets, datasets, checkpoints, pretrained weights, videos, images, caches, or environment directories are included.

## Public Release Plan

The full public release README will be expanded later with sections inspired by common academic code repositories, including Installation, Data Preparation, Avatar Creation, Evaluation, Training, Citation, License, and Acknowledgements.
